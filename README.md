# 🌾 Crop Recommendation System

Recommends the best crop to grow based on soil nutrients (N, P, K), pH,
temperature, humidity and rainfall, using a Random Forest model (about 99% accuracy).

## Live demo
https://crop-recommender-suma.streamlit.app

## Tech
Python, scikit-learn, Streamlit, Jupyter Notebook

## Run locally
pip install -r requirements.txt
python -m streamlit run app.py
